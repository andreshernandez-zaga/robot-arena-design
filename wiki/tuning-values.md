# Tuning Values

> Starting values for game-testing (owner, 2026-10-26). Change them freely as testing shows what works, and log real changes in the [Decision Log](decision-log.md). Nothing here is final. The rules these values feed are in [Match Dynamics](match-dynamics.md).

## Match

| Parameter | Starting value | Status | Notes |
|---|---|---|---|
| Action pool per player per turn | 15 orders | Provisional | Counts orders, not tempos |
| Bonus actions | +1 to +2 | Open | From abilities or bonuses; mechanics not defined |
| Turn length | 16 tempos | Provisional | Each robot's track; fits about 8 standard actions |
| Standard action | 2 tempos | Provisional | Most actions |
| Simple action (e.g. turn one hex side) | 1 tempo | Provisional | |
| Skill | 2 tempos and up | Provisional | Longer casts give prepared robots time to react |
| Excellent at an action | 1 tempo (1.5 if fractions work) | Provisional | From stats or class |
| Reaction | 1 tempo | Provisional | Modifiers may change it |
| Defensive reaction cost | 0 actions (free) | Provisional | Starting point. Alternative: spend from the next turn's pool |
| Offensive reaction cost | Saved actions | Provisional | Saved actions unused at the end of the turn are lost |
| Facing arcs | Front 3 sides, side 2, back 1 | Open | Claude's candidate |
| Reactions per robot per turn | 1 | Provisional | A robot attacked by two opponents can only answer one |
| Default reaction success | Low (number Open) | Provisional | Better reactions come from stats and abilities |
| Initiative ties | Both happen at once | Open | Part of the initiative proposal |
| Squad size | 4–6 robots | Open | |
